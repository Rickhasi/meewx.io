
MeewX Website (ready for GitHub Pages)
=====================================

This package contains a simple, SEO-friendly, neon-themed landing page for the MeewX meme coin.

Files:
- index.html
- style.css
- script.js
- assets/MEEWX.png         (hero image)
- assets/rocket-sound.wav  (2-second AI-style rocket sound)
- README.txt

Usage (quick):
1. Unzip and open index.html locally to preview.
2. Upload files to a GitHub repository named 'meewx.io' (or any name) and enable GitHub Pages in Settings -> Pages -> Source: main branch / root.
3. Visit: https://<your-github-username>.github.io/meewx.io/

Important notes for GitHub Pages & SEO:
- To have the final domain 'www.meewx.io', configure your DNS provider with a CNAME record pointing to <your-github-username>.github.io and add 'www.meewx.io' as a custom domain in the repo Pages settings.
- Keep the repository under your account (do not add other collaborators) so only you can manage content.
- For best SEO: publish additional pages (About, Whitepaper, Contact), add real content, and verify site in Google Search Console.

If you need a step-by-step beginner-friendly tutorial, follow the included 'UPLOAD_INSTRUCTIONS.txt' in this archive.
